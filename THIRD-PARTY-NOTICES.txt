THIRD-PARTY SOFTWARE NOTICES AND INFORMATION

CodeBrix.Platform.Fonts.Roboto is a CodeBrix-family redistribution of the
Roboto font family, packaged as a .NET 10 NuGet library. Roboto covers the
Latin and Cyrillic scripts and modern (monotonic) Greek, but not the
polytonic Greek of the Greek Extended block, and not Armenian or Georgian,
so this package additionally bundles three Noto Sans companion families that
supply those scripts. The package therefore incorporates four pieces of
third-party material:

  1. The Roboto font family (SIL OFL 1.1) — the actual `.ttf` font files
     themselves, originally designed by Christian Robertson and maintained
     by the Google Fonts team as the Roboto Project.
  2. The Noto Sans font family (SIL OFL 1.1) — the polytonic Greek companion.
  3. The Noto Sans Armenian font family (SIL OFL 1.1) — the Armenian companion.
  4. The Noto Sans Georgian font family (SIL OFL 1.1) — the Georgian companion.

The CodeBrix-authored parts of this package — the `.csproj`, the
buildTransitive `.targets` file, the `.ttf.manifest` JSON files, the
`CODEBRIX-DEVELOP.json` descriptor, the `.uprimarker` marker, the
documentation, and the packaging metadata — are original to the
CodeBrix family and contain no third-party source code. They are released,
together with the bundled font files, under the SIL Open Font License,
Version 1.1, the same license as the fonts. The full license text is bundled
with this repository as `OFL.txt` at the repository root and is also packaged
inside the produced NuGet under the same name.

2. Noto Sans Font Family (polytonic Greek companion)
   -------------------------------------------------
   Project URL:    https://github.com/notofonts/latin-greek-cyrillic
   Copyright:      Copyright 2022 The Noto Project Authors
                   (https://github.com/notofonts/latin-greek-cyrillic)
   License:        SIL Open Font License, Version 1.1

   Note on naming: the Noto Sans copyright statement declares NO Reserved Font
   Name, so SIL OFL 1.1 condition 3 does not apply to this family. The `.ttf`
   files are redistributed bit-for-bit unmodified.

   Why it is bundled: Roboto carries only modern, monotonic Greek. It covers 75
   code points of the Greek and Coptic block (U+0370-U+03FF) and just one code
   point of the Greek Extended block (U+1F00-U+1FFF), and it does not carry the
   combining marks polytonic Greek would otherwise be composed from (no U+0313
   psili, U+0314 dasia, U+0342 perispomeni or U+0345 ypogegrammeni). Ancient
   polytonic Greek therefore cannot be rendered from Roboto at all. Noto Sans
   supplies the complete Greek Extended block — all 233 assigned code points —
   plus 121 code points of Greek and Coptic, in a sans design consistent with
   Roboto.

   Files redistributed from this upstream project (binary `.ttf` files):

     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-Bold.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-BoldItalic.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-ExtraBold.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-ExtraBoldItalic.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-Italic.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-Light.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-LightItalic.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-Medium.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-MediumItalic.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-Regular.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-SemiBold.ttf
     - src/CodeBrix.Platform.Fonts.Roboto/Fonts/NotoSans-SemiBoldItalic.ttf

   Modifications made during redistribution:
     - Only the six weights Light (300) through ExtraBold (800) are shipped as
       static instances, in the Normal stretch, upright and italic. The upstream
       Thin (100), ExtraLight (200) and Black (900) static instances, and the
       Condensed, SemiCondensed and ExtraCondensed stretches, are not included.
       (Those weights and widths remain reachable through the bundled variable
       font, which carries both the `wght` and `wdth` axes.)
     - The upstream upright variable font `NotoSans-VariableFont_wdth,wght.ttf`
       was renamed to `NotoSans.ttf`. No `.ttf` binary content was altered.
     - The separate upstream italic variable font
       `NotoSans-Italic-VariableFont_wdth,wght.ttf` is not included; italic
       styles are provided through the static instances, matching how Roboto
       itself is packaged here.
